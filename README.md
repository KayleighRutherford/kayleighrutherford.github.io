# kayleigh-website

Personal site — bio, experience, publications, contact. One page, self-contained.

## Structure

```
src/template.html      the actual source: edit this for copy, layout, or style
assets/fonts/           IBM Plex Serif/Sans/Mono, woff2
assets/headshot.jpg      profile photo (cropped square, color-corrected sRGB)
build.py                inlines fonts + photo into template → index.html
index.html               built output — do not hand-edit, regenerated by build.py
```

## Editing

1. Edit `src/template.html` (plain HTML/CSS, no build tooling required to read it).
2. To change the photo, replace `assets/headshot.jpg` (same filename) — crop it
   square yourself, or ask Claude to.
3. Rebuild:

   ```
   python3 build.py
   ```

4. Open `index.html` directly in a browser to preview.

## Why the split

Fonts and the photo are embedded as base64 data URIs so the final page is a
single file with zero external requests — it'll render identically anywhere,
including if you email the file or drop it on any static host. Those blobs
are large binary text, so they're kept out of the editable template and
spliced in at build time instead.

## Deploying

`index.html` is a static file — drop it on any static host (GitHub Pages,
Netlify, Vercel, S3, etc.). For GitHub Pages from this repo: push to GitHub,
then enable Pages on the `main` branch, root directory, in repo Settings.
